# Roadmap

This roadmap uses a Now, Next, Later format. Dates are rough. Each phase has a clear goal and a test to know when it's done.

## Done
* **User research:** survey with 22 students, 3 interviews ([Research.md](Research.md))
* **Personas** ([Personas.md](Personas.md))
* **User stories** ([UserStories.md](UserStories.md))
* **PRD** ([PRD.md](PRD.md))

## Now: Version 1.0 (MVP)
**Rough timing:** 8 to 10 weeks

**Goal:** Prove that busy students will keep using a planner when setup takes almost no effort.

| Feature | Stories |
|---|---|
| F1 Quick add | US01, US03 |
| F2 Paste from chat | US02 |
| F3 Repeating commitments | US05 |
| F4 Week view | US04 |
| F5 Today screen | US06 |
| F6 Clash warning | US07 |
| F7 Commitment reminders | US09 |

**Plan**
1. Wireframes and a clickable prototype (weeks 1 to 2)
2. Test the prototype with 5 busy students (week 3)
3. Fix what testing shows (week 4)
4. Build (weeks 5 to 9)
5. Beta with 20 to 30 students from 2 universities (week 10)

**Done when**
* 70% of beta users finish first time setup
* 40% are still active in week 2
* Adding a task takes under 10 seconds on average

## Next: Version 1.1
**Rough timing:** 4 to 6 weeks after launch

**Goal:** Help students fix their plan fast and move tasks that have no deadline.

| Feature | Stories |
|---|---|
| One tap reschedule | US08 |
| Soft target dates | US10 |
| Mark tasks as graded or high stakes | US12 |

**Done when**
* 25% of users are still active in week 4
* Users move tasks with one tap more often than they delete and add them again

## Later
These depend on what we learn from version 1.

| Idea | Stories | Why wait |
|---|---|---|
| Suggest what to do first today | US13 | Needs real usage data to suggest well |
| Nudge for tasks that haven't moved | US11 | Could feel naggy. Test reminders first. |
| Bangla support | None yet | Open question from the PRD |
| Offline mode | None yet | Open question from the PRD |

## Not planned
* Syncing with Canvas or Google Classroom
* File storage
* Group or class features

See section 4 of the [PRD](PRD.md) for why.

## How this roadmap changes
After each phase, check the metrics in [Metrics.md](Metrics.md). If students drop off in week 2, fix that before adding anything new. A new feature won't help if people have already left.
